# Review shared knowledge

- Identify who should receive the knowledge. Keep decisions about a single project in that project's approved context.
- Extract the reusable procedure and replace project details with generic examples. Remove credentials, customer information, private endpoints, paths, and internal identifiers.
- Record how the procedure was verified and which assumptions another project would need to check.
- Return the proposed `SKILL.md` and the verification notes for human review. The maintainer publishes the approved version to the shared Git directory.
